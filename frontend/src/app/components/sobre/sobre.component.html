OpinaMAIS

Monitoramento de Serviços Públicos via Análise de Sentimentos

Autores: João V. M. Vantil e Giulia C. Bezerra

Entre 2020 e 2025 acompanhamos centenas de conversas públicas no Twitter para descobrir, em tempo real, o que as pessoas pensam sobre serviços como educação, saúde e transporte. Os resultados são exibidos em painéis claros que indicam se o sentimento da população é positivo, negativo ou neutro em cada tema.

O OpinaMAIS transforma mensagens do Twitter em insights úteis para a gestão pública. O processo segue quatro passos simples:

  1. Captura das postagens sobre serviços públicos.
  2. Limpeza do texto para retirar links e ruídos.
  3. Leitura do sentimento — identificamos se a opinião é favorável, crítica ou neutra.
  4. Visualização em dashboards interativos que mostram tendências e comparações ao longo do tempo.

Dessa forma, qualquer pessoa pode acompanhar, de maneira simples, como a sociedade avalia as principais políticas e serviços oferecidos pelo Estado.

  1. Scraping direcionado — scripts Python + Selenium executam queries avançadas no Twitter, contornando limites da API oficial. Para cada tweet registramos ID, timestamp, texto bruto, likes, retweets e views.
  2. Normalização do texto — remoção de URLs, hashtags, menções e emojis via RegEx; redução de múltiplos espaços; conversão de números (“1,2K” → 1200). O resultado é serializado em JSON e persiste no MongoDB.
  3. Inferência BERT — usamos o modelo lipaoMai/BERT-sentiment-analysis-pt (Hugging Face) para classificar cada tweet em positivo, negativo ou neutro. Tweets com score < 0,70 são rebaixados para neutros a fim de reduzir falsos-positivos.
  4. APIs & Visualização — uma REST API Spring Boot fornece consultas paginadas e agregadas. No frontend Angular 17 + PrimeNG, dashboards Plotly/Chart.js exibem séries temporais, distribuições por categoria e filtros interativos (data, sentimento, palavra-chave).
  • Scraper automatizado
  • Processamento & classificação BERT em lote
  • Dashboards responsivos
  • Gráficos dinâmicos com filtros avançados
  • Arquitetura extensível para novas redes
Scraper: Python · Requests · BeautifulSoup · Selenium IA/PLN: Hugging Face BERT · Transformers Banco: MongoDB (NoSQL) Backend: Spring Boot (REST) Frontend: Angular 17 · PrimeNG v19 Gráficos: Plotly · Chart.js
